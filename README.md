# git-repo

这是本机专门用于 Git 版本管理的仓库目录。

## 环境信息

- Git 安装位置：`D:\Git`（版本 `2.56.0.windows.2`）
- 仓库位置：`D:\宁致远\git-repo`
- 默认分支：`main`

## 常用命令

```bash
git status                 # 查看状态
git add .                  # 暂存全部修改
git commit -m "说明"        # 提交
git log --oneline --graph  # 查看历史
git remote add origin <URL>  # 关联远程仓库
git push -u origin main    # 首次推送
```
